## 👋 About me

Full-stack developer since 2019, from **Rio Grande do Sul, Brazil**. Founder of
[**Argonauts**](https://argonauts.com.br) — a small studio building products end to end.

Most developers stop at `git push`. I go one layer down: I ship the app **and** run the
machine underneath it — Docker, Hyper-V, Postgres tuning, firewall, own server behind a
static IP.

- 🧩 **Product-first** — auth, payments, AI, mobile and PDF export in the same codebase
- 🎨 **Design is not an afterthought** — GSAP, Three.js, motion, design systems, real SEO
- 🤖 **AI in production, not demos** — multimodal assistant with file upload, voice and report generation
- 🛠️ **Infra included** — Docker, Hyper-V, VPS, n8n, WhatsApp API, self-hosted Postgres/Redis/Qdrant
- 🌍 **Portuguese** native · **English** for technical work · time zone friendly to the Americas & morning-overlap with Europe

## ⚙️ How I work

| | |
|---|---|
| **Scope** | Design → front end → API → database → deploy → the server it runs on |
| **Performance** | Real cases: killed an N+1 that fired **291 queries per request**, added the indexes on production Postgres |
| **Security** | Auth written from scratch (OAuth, httpOnly JWT, email verification, rate limiting) + audited and fixed cross-account data leaks |
| **Payments** | Mercado Pago with **idempotent webhooks** — no double charges, no ghost subscriptions |
| **Delivery** | Same product on web and mobile, by one person, shipped continuously |
